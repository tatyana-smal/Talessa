# Дизайн-токени Talessa

Усі токени живуть в одному місці: `src/index.css`, блок `:root`. Назви описують **роль**, а не колір.
Решта CSS бере значення звідти. Нижче: що це за токени, звідки значення (аудит) і що свідомо лишилося поза набором.

## Кольори (7 ролей)

| Токен | Значення | Для чого |
| --- | --- | --- |
| `--canvas` | `#fcf1ea` | Фон сторінки, поля форми, підпис на темній кнопці (Figma: Color Back) |
| `--surface` | `#f9dcc2` | Поверхні: перша картка, зміст, повідомлення, підвал, кнопка «Про мене» на телефоні (Color Block) |
| `--line` | `#baaa9e` | Лише декоративні лінії: розділювачі |
| `--accent` | `#805131` | Заголовки-мітки на сторінках застосунків, фокус, чекбокс |
| `--text` | `#402510` | Основний текст і заливка кнопок (Color Текст = Botton 1) |
| `--text-muted` | `#6b5646` | Підписи, плейсхолдер, **межі** полів, карток, контурних кнопок (≥ 3:1) |
| `--danger` | `#b00020` | Помилки форми |

Помилка (відтінок 349°) явно відрізняється від акценту (24°).

## Контраст (WCAG), пари «текст на фоні»

| Пара | Контраст |
| --- | --- |
| `text` / `canvas` | 12,69:1 |
| `text` / `surface` | 10,77:1 |
| `canvas` / `text` (підпис на кнопці) | 12,69:1 |
| `text-muted` / `canvas` | 6,21:1 |
| `text-muted` / `surface` | 5,27:1 |
| `accent` / `canvas` | 6,02:1 |
| `accent` / `surface` | 5,11:1 |
| `danger` / `canvas` | 6,60:1 |
| `danger` / `surface` | 5,60:1 |
| межа поля `text-muted` / `canvas` (не текст, треба ≥ 3:1) | 6,21:1 |
| `line` / `canvas` (лише декор) | 2,03:1 |

Пар нижче 4,5:1 у наборі немає. Раніше такими були: текст з `opacity: 0,65` (4,44:1), плейсхолдер браузера (4,44:1), межа поля з прозорістю (2,16:1, для меж треба ≥ 3:1) — усе замінено на `text-muted`.
Не перевіряється числом: текст поверх фото (hero), бо залежить від зображення.

## Типографіка

Шрифти: `--font-heading` = Lora Medium (500); `--font-body` = Inter Regular (400); жирний (700) лише для `<b>` усередині тексту.

| Токен | Десктоп → ≤1100 px | Висота рядка | Трекінг | Для чого |
| --- | --- | --- | --- | --- |
| `--fs-display` | 64 → 40 px | 1,2 → 1,1 | 0 | Головний заголовок, H1 (Figma: Text H1 / Tablet h1) |
| `--fs-heading` | 36 → 32 px | 1,2 | 0 | Заголовки карток, блоків, розділів (Text H2 / Tablet h2) |
| `--fs-title-s` | 20 px | 1,2 | 0 | Малий заголовок Lora: колонка підвалу, «Зміст» |
| `--fs-lead` | 24 → 20 px | 1,3 → 1,2 | 0 | Абзац hero, меню й описи на десктопі (Text / Tablet Text) |
| `--fs-body` | 16 px | 1,5 | 0 | Форми, юридичний текст, підвал; меню й кнопки на планшеті (Tablet text button) |
| `--fs-caption` | 14 px | 1,4 | 0 | Дата редакції, копірайт, підписи |

Шрифти головної сторінки (display, heading, lead) лишилися без змін — це значення з Figma.
Hero на десктопі, планшеті й телефоні задано в `cqw`, щоб текст масштабувався разом із картинкою; це ті самі токени, виражені в частках ширини.

## Відступи

`--space-1` 8 px · `--space-2` 12 px · `--space-3` 16 px · `--space-4` 24 px · `--space-5` 32 px.
Округлення: до найближчого кроку, при рівній відстані — вгору (10 → 12, 14 → 16, 20 → 24).
Проміжок між картками застосунків став 12 px замість 10 px (Figma) — треба переглянути в макеті.

## Радіуси

`--radius-control` 24 px (кнопки, чип мови, поля, випадне меню) · `--radius-card` 50 px (перша картка, картинки «Дизайн/Блог», зміст, повідомлення).

## Пропорції картинок

| Токен | Значення | Для чого |
| --- | --- | --- |
| `--ratio-card` | 5 / 4 | Обкладинка картки застосунку (350×280) |
| `--ratio-picture` | 336 / 232 | Картинка у блоках «Дизайн/Блог» |
| `--ratio-hero-desktop` / `-tablet` / `-mobile` | 2000/779 · 1536/784 · 780/1234 | Єдине полотно hero для кожного розміру екрана |

Портретного типу картинок поки немає (блок «Про мене» без фото).

| Значення | Де |

## Відомі розбіжності з макетом

- Темні рамки карток тепер `text-muted` (`#6b5646`), а не `#402510`.
- Підпис темних кнопок — `canvas` (`#fcf1ea`) замість `#e7d9ce`.
- Підвал — `surface` замість `#f6e3d6`.
- Сторінка `/health` перейшла на кольори основних сторінок. Картинки смуг у ній (`src/assets/img/health/`) мають власний мʼятний фон, його можна змінити лише новим експортом із Figma.
